📊 A. 动效功能总览

根据分析,项目包含以下8大动效系统:

1⃣ 序列帧动画系统 (核心动效)

- 功能: 将数百张图片连续播放形成流畅动画
- 触发方式: 滚轮滚动驱动或自动播放
- 应用场景: 产品360度展示、功能演示、场景变化
- 特点: 像播放视频一样流畅,但可精确控制每一帧

2⃣ GSAP滚动动画系统

- 功能: 滚动时固定元素,继续滚动驱动动画播放
- 触发方式: ScrollTrigger监听滚动位置
- 应用场景: 产品特性分步展示、文字滚动切换、缩放动画
- 特点: 虚拟滚动距离可达5000px+,实现精细控制

3⃣ 3D模型交互展示

- 功能: 加载GLB格式3D模型,支持拖拽旋转、子模型切换
- 触发方式: 用户拖拽或按钮点击
- 应用场景: AC Pro产品4种配色、DH产品6种配置展示
- 特点: 支持环境光贴图(HDR)增强真实感

4⃣ 视口触发动画(IntersectionObserver)

- 功能: 元素进入屏幕可见区域时自动播放动画
- 触发方式: 滚动到元素位置
- 应用场景: 淡入淡出、上滑入场、图片加载、数字滚动
- 特点: 自动管理,无需手动监听滚动

5⃣ 数字滚动动画

- 功能: 数字从0快速滚动到目标值
- 触发方式: 元素进入视口
- 应用场景: 数据统计(如"200万+充电器")、性能指标展示
- 特点: 支持千分位格式化、自定义持续时间

6⃣ 轮播动画系统

- 功能: 水平/垂直滑动轮播,支持无限循环
- 触发方式: 用户滑动、按钮点击、触控板横向滚动、自动定时
- 应用场景: 产品特性卡片、认证标识展示、合作伙伴logo
- 特点: 触控板横向滚动支持(Mac触控板友好)

7⃣ 视频控制系统

- 功能: 视频播放 + 时间轴事件触发
- 触发方式: 自动播放或用户点击
- 应用场景: 首屏大视频背景、产品功能演示、选项卡视频切换
- 特点: 根据播放时间触发不同动作(如2秒后显示文字)

8⃣ CSS关键帧动画

- 功能: 纯CSS实现的循环动画
- 触发方式: 页面加载自动播放或类名切换
- 应用场景: loading动画、图标旋转、进度条、上下浮动
- 特点: 性能最优,不占用JS线程

1⃣ 序列帧动画 - 实现原理拆解

方案A: 自定义Canvas序列帧 (项目核心技术)

原理流程:
┌─────────────┐
│ 1. 加载图片  │ → 并发加载200+张图片到数组
└──────┬──────┘
        ↓
┌─────────────┐
│ 2. 监听滚轮  │ → Silky类捕获wheel事件
└──────┬──────┘
        ↓
┌─────────────┐
│ 3. 计算帧号  │ → 阻尼算法+lerp插值计算当前帧
└──────┬──────┘
        ↓
┌─────────────┐
│ 4. Canvas绘制│ → 清空画布 → 绘制当前帧图片
└──────┬──────┘
        ↓
┌─────────────┐
│ 5. RAF循环   │ → requestAnimationFrame下一帧
└─────────────┘

核心技术点:
- Silky平滑滚动引擎: 使用阻尼函数实现丝滑过渡,而非直接跳帧
- lerp插值算法: current = current + (target - current) * 0.1
- Canvas优化: 只绘制变化的区域,避免全屏重绘
- 滚轮方向检测: 正向播放/反向播放自动切换

2⃣ GSAP滚动动画 - 实现原理拆解

固定区域(Pin)动画原理

视觉效果:
┌──────────────────────────────────┐
│        普通内容(可滚动)            │
├──────────────────────────────────┤
│  ╔════════════════════════════╗  │ ← 滚动到这里
│  ║  固定区域(pin: true)        ║  │
│  ║  继续滚动时不移动           ║  │ ← 固定在视口中
│  ║  但内部动画继续播放         ║  │
│  ╚════════════════════════════╝  │
├──────────────────────────────────┤
│        普通内容(可滚动)            │
└──────────────────────────────────┘

技术原理:
1. ScrollTrigger检测元素到达触发点(start: "50% 50%")
2. 设置元素position: fixed,固定在视口
3. 创建虚拟滚动距离(end: "+=5000px")
4. 用户滚动时,元素不动,但progress从0→1变化
5. 根据progress控制内部动画播放
6. 滚动到结束点时,解除fixed,恢复正常流

代码映射:
gsap.timeline({
scrollTrigger: {
    pin: true,              // 固定元素
    trigger: "#element",    // 要固定的元素
    start: "50% 50%",       // 元素中心到达视口中心时触发
    end: "+=5000px",        // 虚拟滚动5000px后结束
    scrub: true,            // 滚动同步(无缓动)
    anticipatePin: 1,       // 提前1个像素预测固定(防止闪烁)
    onUpdate: (self) => {
    // self.progress: 0.0 → 1.0
    // 用这个值控制序列帧/文字位置/缩放等
    }
}
});

┌──────────────┐

5⃣ 数字滚动动画 - 实现原理拆解

算法原理:
目标: 从0滚动到70,000,持续1500ms

1. 计算步数:
    steps = Math.ceil(1500ms / 10ms) = 150步

2. 计算每步增量:
    increment = Math.ceil(70000 / 150) = 467

3. 定时器循环:
    10ms: 0 → 467
    20ms: 467 → 934
    30ms: 934 → 1401
    ...
    1500ms: 69533 → 70000

4. 格式化显示:
    70000 → "70,000" (千分位)

5. 达到目标后清除定时器

技术细节:
- 使用setInterval而非requestAnimationFrame(因为需要固定时间间隔)
- 最后一步确保精确到达目标值(防止累计误差)
- 支持自定义时间和步长

6⃣ 轮播动画 - 实现原理拆解

无限循环滚动原理

DOM结构技巧:
┌──────────────────────────────────┐
│ [A] [B] [C] [D] [A] [B] [C] [D] │ ← 内容复制两次
└──────────────────────────────────┘
↑                        ↑
起始位置               重置点

滚动逻辑:
1. 每20ms向左移动1px (scrollLeft -= 1)
2. 当滚动到第一组末尾时(scrollLeft <= threshold)
3. 立即重置到第二组开始位置(scrollLeft = reset_position)
4. 因为内容完全相同,用户感觉不到跳跃
5. 循环往复,形成无限滚动效果

鼠标悬停暂停:
- timeStop.current = true → 停止 scrollLeft 更新
- timeStop.current = false → 恢复更新

问题: Slick默认不支持触控板横向滚动

DOM结构:

- 切换流畅无卡顿(视频已加载)

// 1. IntersectionObserver 动画触发器
export function animation() {
const elements = document.querySelectorAll("[animation]");
elements.forEach(el => el.style.opacity = 0);

const observer = new IntersectionObserver(
    (entries) => {
    entries.forEach(({ isIntersecting, target }) => {
        if (isIntersecting) {
        const [animType, delay = 0] = target.getAttribute("animation").split(" ");
        target.classList.add(`animate__${animType}`, "animate__animated");
        target.style.animationDelay = `${delay}ms`;

        target.addEventListener("animationend", () => {
            target.classList.remove(`animate__${animType}`);
            target.style.opacity = 1;
        }, { once: true });

        observer.unobserve(target);
        }
    });
    },
    { threshold: 0.1 }
);

elements.forEach(el => observer.observe(el));
return observer;
}

// 2. 通用观察者
export function observer(dom, callback) {
const obs = new IntersectionObserver(
    (entries) => {
    entries.forEach(({ isIntersecting, target }) => {
        if (isIntersecting) {
        obs.unobserve(target);
        callback(target);
        }
    });
    },
    { threshold: 0.1 }
);
obs.observe(dom);
return obs;
}

// 3. 数字滚动动画
export function numToMax(
timeSet,
setFn,
maxNum,
useComma = false,
intervalMs = 10,
duration = 1500
) {
const steps = Math.ceil(duration / intervalMs);
const increment = Math.ceil(maxNum / steps);
let current = 0;

timeSet = setInterval(() => {
    current += increment;
    if (current > maxNum) current = maxNum;

    const display = useComma
    ? current.toString().replace(/\B(?=(\d{3})+(?!\d))/g, ",")
    : current;

    setFn(display);

    if (current >= maxNum) clearInterval(timeSet);
}, intervalMs);

return timeSet;
}

// 4. 节流函数
export function throttle(func, wait = 100) {
let timeout = null;
let previous = 0;

return function(...args) {
    const now = Date.now();
    const remaining = wait - (now - previous);

    if (remaining <= 0 || remaining > wait) {
    if (timeout) {
        clearTimeout(timeout);
        timeout = null;
    }
    previous = now;
    func.apply(this, args);
    } else if (!timeout) {
    timeout = setTimeout(() => {
        previous = Date.now();
        timeout = null;
        func.apply(this, args);
    }, remaining);
    }
};
}

// 5. 防抖函数
export function debounce(func, wait = 300) {
let timeout;
return function(...args) {
    clearTimeout(timeout);
    timeout = setTimeout(() => func.apply(this, args), wait);
};
}

// 6. 平滑滚动
export function scrollThis(dom) {
if (!dom) return;
const offsetTop = dom.getBoundingClientRect().top + window.scrollY;
window.scrollTo({
    top: offsetTop,
    behavior: "smooth"
});
}

// 7. 触控板横向滚动处理器
export function createHorizontalWheelHandler(sliderRef) {
const handleWheel = (e) => {
    const { deltaX, deltaY } = e;

    // 检测是否为横向滚动
    if (Math.abs(deltaX) > Math.abs(deltaY)) {
    e.preventDefault();

    // 检测是否为触控板(小幅滚动)
    if (Math.abs(deltaY) < 50) {
        if (deltaX > 0) {
        sliderRef.current?.slickNext();
        } else {
        sliderRef.current?.slickPrev();
        }
    }
    }
};

const element = sliderRef.current?.innerSlider?.list;
if (element) {
    element.addEventListener('wheel', handleWheel, { passive: false });
    return () => element.removeEventListener('wheel', handleWheel);
}

return () => {};
}

// 8. lerp 插值函数
export function lerp(start, end, factor = 0.1) {
return start + (end - start) * factor;
}

'use client';
import React, { useRef, useEffect, forwardRef, useImperativeHandle, useState, createContext, useContext } from
"react";
import pLimit from "p-limit";

// 平滑滚动引擎
class Silky {
constructor(config) {
    this.config = {
    x: 0,
    target: 0,
    ease: 0.1,
    speed: 0,
    ...config
    };
}

lerp(start, end, factor) {
    return start + (end - start) * factor;
}

update() {
    this.config.x = this.lerp(this.config.x, this.config.target, this.config.ease);
    this.config.speed = this.config.target - this.config.x;
    return this.config.x;
}

addTarget(delta) {
    this.config.target += delta;
}

setTarget(value) {
    this.config.target = value;
}

reset() {
    this.config.x = 0;
    this.config.target = 0;
    this.config.speed = 0;
}
}

// Context用于子组件通信
const AnimationContext = createContext(null);

// ShowFrame: 仅在指定帧区间显示子组件
const ShowFrame = ({ start, end, onChange, children }) => {
const { current } = useContext(AnimationContext);
const isVisible = current >= start && current <= end;

useEffect(() => {
    if (isVisible && onChange) {
    onChange(current);
    }
}, [current, isVisible]);

return isVisible ? <div>{children}</div> : null;
};

// 主组件
const Animation = forwardRef(({
images = [],        // 图片URL数组
time = 3000,        // 自动播放时长(ms)
autoPlay = false,   // 是否自动播放
loop = false,       // 是否循环
onChange,           // 帧变化回调
onEnd,              // 播放结束回调
children
}, ref) => {
const canvasRef = useRef(null);
const imagesRef = useRef([]);
const currentFrameRef = useRef(0);
const silkyRef = useRef(new Silky({ ease: 0.15 }));
const rafRef = useRef(null);
const [current, setCurrent] = useState(0);
const [isLoaded, setIsLoaded] = useState(false);
const isPlayingRef = useRef(false);
const scrollEnabledRef = useRef(false);

// 加载图片
const loadImages = async () => {
    const limit = pLimit(6); // 并发限制
    const loadPromises = images.map((src, index) =>
    limit(async () => {
        const img = new Image();
        img.src = src;
        await new Promise((resolve, reject) => {
        img.onload = resolve;
        img.onerror = reject;
        });
        imagesRef.current[index] = img;
    })
    );

    await Promise.all(loadPromises);
    setIsLoaded(true);
};

// 渲染当前帧
const renderFrame = (frameIndex) => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    const ctx = canvas.getContext('2d');
    const img = imagesRef.current[frameIndex];

    if (img && img.complete) {
    // 清空画布
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    // 绘制图片(保持宽高比)
    const scale = Math.max(
        canvas.width / img.width,
        canvas.height / img.height
    );
    const x = (canvas.width - img.width * scale) / 2;
    const y = (canvas.height - img.height * scale) / 2;

    ctx.drawImage(img, x, y, img.width * scale, img.height * scale);
    }
};

// 动画循环
const animate = () => {
    if (!isPlayingRef.current) return;

    const silky = silkyRef.current;
    const position = silky.update();

    // 计算当前帧
    let frameIndex = Math.floor(Math.abs(position) % imagesRef.current.length);

    if (currentFrameRef.current !== frameIndex) {
    currentFrameRef.current = frameIndex;
    setCurrent(frameIndex);
    renderFrame(frameIndex);
    onChange?.(frameIndex);
    }

    rafRef.current = requestAnimationFrame(animate);
};

// 滚轮控制
const handleWheel = (e) => {
    if (!scrollEnabledRef.current) return;

    e.preventDefault();
    silkyRef.current.addTarget(e.deltaY * 0.05);
};

// 暴露给父组件的方法
useImperativeHandle(ref, () => ({
    load: loadImages,
    play: (startFrame = 0, reverse = false) => {
    currentFrameRef.current = startFrame;
    silkyRef.current.setTarget(startFrame);
    isPlayingRef.current = true;
    animate();
    },
    stop: () => {
    isPlayingRef.current = false;
    cancelAnimationFrame(rafRef.current);
    },
    changeScroll: (enabled) => {
    scrollEnabledRef.current = enabled;
    },
    goto: (frame) => {
    currentFrameRef.current = frame;
    renderFrame(frame);
    setCurrent(frame);
    }
}));

// 初始化
useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    // 设置Canvas尺寸
    const resize = () => {
    canvas.width = canvas.offsetWidth;
    canvas.height = canvas.offsetHeight;
    renderFrame(currentFrameRef.current);
    };

    resize();
    window.addEventListener('resize', resize);

    // 滚轮监听
    canvas.addEventListener('wheel', handleWheel, { passive: false });

    return () => {
    window.removeEventListener('resize', resize);
    canvas.removeEventListener('wheel', handleWheel);
    cancelAnimationFrame(rafRef.current);
    };
}, []);

// 自动播放
useEffect(() => {
    if (autoPlay && isLoaded) {
    const frameRate = 1000 / 30; // 30fps
    const totalFrames = imagesRef.current.length;
    let frame = 0;

    const interval = setInterval(() => {
        renderFrame(frame);
        setCurrent(frame);
        onChange?.(frame);

        frame++;
        if (frame >= totalFrames) {
        if (loop) {
            frame = 0;
        } else {
            clearInterval(interval);
            onEnd?.();
        }
        }
    }, frameRate);

    return () => clearInterval(interval);
    }
}, [autoPlay, isLoaded, loop]);

return (
    <AnimationContext.Provider value={{ current }}>
    <div style={{ position: 'relative', width: '100%', height: '100%' }}>
        <canvas
        ref={canvasRef}
        style={{
            width: '100%',
            height: '100%',
            display: 'block'
        }}
        />
        {isLoaded && children}
    </div>
    </AnimationContext.Provider>
);
});

Animation.ShowFrame = ShowFrame;
Animation.displayName = 'Animation';

export default Animation;

// src/hooks/useIntersectionAnimation.js
import { useEffect } from 'react';

export function useIntersectionAnimation() {
useEffect(() => {
    const elements = document.querySelectorAll("[data-anim]");

    // 初始隐藏
    elements.forEach(el => {
    el.style.opacity = '0';
    el.style.transform = 'translateY(20px)';
    });

    const observer = new IntersectionObserver(
    (entries) => {
        entries.forEach(({ isIntersecting, target }) => {
        if (isIntersecting) {
            const animType = target.getAttribute("data-anim");
            const delay = target.getAttribute("data-delay") || 0;

            setTimeout(() => {
            target.classList.add(`animate__${animType}`, "animate__animated");

            target.addEventListener("animationend", () => {
                target.style.opacity = '1';
                target.style.transform = 'none';
                target.classList.remove(`animate__${animType}`, "animate__animated");
            }, { once: true });
            }, delay);

            observer.unobserve(target);
        }
        });
    },
    {
        threshold: 0.1,
        rootMargin: '0px 0px -10% 0px' // 进入视口10%时触发
    }
    );

    elements.forEach(el => observer.observe(el));

    return () => observer.disconnect();
}, []);
}

// src/components/CountUpNumber.jsx
'use client';
import { useState, useEffect, useRef } from 'react';

export default function CountUpNumber({
end,                  // 目标数字
duration = 1500,      // 持续时间(ms)
useComma = false,     // 是否使用千分位
suffix = '',          // 后缀(如 '+', 'kW')
trigger = 'viewport'  // 触发方式: 'viewport'(进入视口) | 'mount'(立即)
}) {
const [count, setCount] = useState(0);
const elementRef = useRef();
const hasTriggered = useRef(false);

const startCount = () => {
    if (hasTriggered.current) return;
    hasTriggered.current = true;

    const intervalMs = 10;
    const steps = Math.ceil(duration / intervalMs);
    const increment = Math.ceil(end / steps);
    let current = 0;

    const timer = setInterval(() => {
    current += increment;
    if (current > end) current = end;

    setCount(current);

    if (current >= end) clearInterval(timer);
    }, intervalMs);
};

useEffect(() => {
    if (trigger === 'mount') {
    startCount();
    return;
    }

    // 进入视口触发
    const observer = new IntersectionObserver(
    ([entry]) => {
        if (entry.isIntersecting) {
        startCount();
        observer.disconnect();
        }
    },
    { threshold: 0.5 }
    );

    if (elementRef.current) {
    observer.observe(elementRef.current);
    }

    return () => observer.disconnect();
}, []);

const displayValue = useComma
    ? count.toLocaleString('en-US')
    : count;

return (
    <span ref={elementRef}>
    {displayValue}{suffix}
    </span>
);
}

    const container = containerRef.current;

    // 复制内容以实现无缝循环
    const content = container.querySelector('.scroll-content');
    const clone = content.cloneNode(true);
    container.appendChild(clone);

    const totalWidth = items.length * (itemWidth + gap);
    let scrollLeft = direction === 'left' ? 0 : totalWidth;

    const scroll = () => {
    if (isPausedRef.current) return;

    if (direction === 'left') {
        scrollLeft += 1;
        if (scrollLeft >= totalWidth) {
        scrollLeft = 0;
        }
    } else {
        scrollLeft -= 1;
        if (scrollLeft <= 0) {
        scrollLeft = totalWidth;
        }
    }

    container.scrollLeft = scrollLeft;
    };

    const timer = setInterval(scroll, speed);

    return () => clearInterval(timer);
}, [items, direction, speed]);

return (
    <div
    ref={containerRef}
    style={{
        width: '100%',
        overflow: 'hidden',
        whiteSpace: 'nowrap',
        position: 'relative'
    }}
    onMouseEnter={() => pauseOnHover && (isPausedRef.current = true)}
    onMouseLeave={() => pauseOnHover && (isPausedRef.current = false)}
    >
    <div
        className="scroll-content"
        style={{
        display: 'inline-flex',
        gap: gap + 'px'
        }}
    >
        {items.map((item, index) => (
        <div
            key={index}
            style={{
            width: itemWidth + 'px',
            flexShrink: 0
            }}
        >
            {item}

'use client';
import { useRef, useEffect, useState } from 'react';
import Animation from './Animation';

export default function MultiStageAnimation({
images,
stages // [{ start: 0, end: 60, loop: true }, ...]
}) {
const animRef = useRef();
const [stageIndex, setStageIndex] = useState(0);
const currentStage = stages[stageIndex];

useEffect(() => {
    animRef.current?.load().then(() => {
    // 播放第一阶段
    animRef.current?.play(currentStage.start);
    });
}, []);

    // 检查是否到达当前阶段末尾
    if (frame >= currentStage.end - 1) {
    if (currentStage.loop) {
        // 循环当前阶段
        animRef.current?.play(currentStage.start);
    } else if (currentStage.next && stageIndex < stages.length - 1) {
        // 进入下一阶段
        const nextIndex = stageIndex + 1;
        setStageIndex(nextIndex);
        animRef.current?.play(stages[nextIndex].start);
    } else {
        // 停止
        animRef.current?.stop();
    }
    }
};

const goToStage = (index) => {
    if (index < 0 || index >= stages.length) return;
    setStageIndex(index);
    animRef.current?.play(stages[index].start);
};

return (
    <div style={{ position: 'relative', width: '100%', height: '100vh' }}>
    <Animation
        ref={animRef}
        images={images}
        onChange={handleFrameChange}
    />

    {/* 阶段指示器 */}
    <div style={{
        position: 'absolute',
        bottom: 20,
        right: 20,
        background: 'rgba(0,0,0,0.7)',
        color: 'white',
        padding: '10px 20px',
        borderRadius: 8
    }}>
        阶段 {stageIndex + 1} / {stages.length}
        {currentStage.loop && ' (循环中)'}
    </div>

    {/* 手动控制按钮(可选) */}
    <div style={{
        position: 'absolute',
        top: 20,
        right: 20,
        display: 'flex',
        gap: 10
    }}>

        onClick={() => goToStage(stageIndex - 1)}
        disabled={stageIndex === 0}
        >
        上一阶段
        </button>
        <button
        onClick={() => goToStage(stageIndex + 1)}
        disabled={stageIndex === stages.length - 1}
        >
        下一阶段
        </button>
    </div>
    </div>
);
}

// src/components/VideoTimeline.jsx
'use client';
import { useRef, useEffect } from 'react';

export default function VideoTimeline({
src,
timeEvents = [], // [{ time: 2, action: () => {} }, ...]
onEnded,
autoPlay = true,
muted = true,
loop = false
}) {
const videoRef = useRef();
const triggeredEvents = useRef(new Set());

useEffect(() => {
    const video = videoRef.current;
    if (!video) return;

    const handleTimeUpdate = () => {
    const currentTime = video.currentTime;

    timeEvents.forEach((event, index) => {
        const eventKey = `event-${index}`;

        if (currentTime >= event.time && !triggeredEvents.current.has(eventKey)) {
        triggeredEvents.current.add(eventKey);
        event.action();
        }
    });
    };

    const handleEnded = () => {
    triggeredEvents.current.clear();
    onEnded?.();
    };

    video.addEventListener('timeupdate', handleTimeUpdate);
    video.addEventListener('ended', handleEnded);

    return () => {
    video.removeEventListener('timeupdate', handleTimeUpdate);
    video.removeEventListener('ended', handleEnded);
    };
}, [timeEvents]);

return (
    <video
    ref={videoRef}
    src={src}
    autoPlay={autoPlay}
    muted={muted}
    loop={loop}
    style={{ width: '100%', height: '100%', objectFit: 'cover' }}
    />
);
}
